# TravelMate 功能清单

本文档对应当前 `master` 分支，记录已经接入并通过测试的功能。当前版本的
核心数据文件覆盖 34 个城市、604 条景点记录。

## 1. 页面与导航

- 首页：展示产品入口和主要旅行功能。
- 注册、登录和退出登录页面。
- 景点列表页：分页、城市筛选、分类筛选和关键词搜索。
- 景点详情页：展示简介、地址、票价、开放时间、分类、图片和地图坐标。
- 我的收藏页：查看并取消收藏。
- 我的行程页：创建、编辑、删除和查看行程。
- 旅行足迹页：在中国地图上展示已覆盖城市、旅行等级、统计数据和海报。
- AI 助手页：旅行问答和自然语言行程规划。
- 管理员用户管理页面对应的后端接口。

## 2. 用户与权限

- 用户注册、登录、退出和 Session 会话管理。
- 用户资料修改：昵称、邮箱。
- 修改密码后使其他会话失效。
- 用户名不区分大小写归一化。
- 密码使用 Werkzeug 哈希保存，不返回密码或密码哈希。
- 写操作使用 CSRF Token 保护。
- 登录失败限流：同一用户名和来源地址在 15 分钟内失败达到阈值后返回
  `429`。
- 管理员分页查询用户、查看用户资料、启用/禁用普通用户。
- 管理员操作写入审计日志，不能通过普通用户状态接口禁用管理员。

## 3. 景点与城市数据

- 34 个城市的核心景点数据，共 604 条记录。
- 景点分类、城市、名称和描述搜索。
- `q` 与 `keyword` 两种关键词参数兼容。
- 景点分页大小限制为 1–100，避免异常请求拖垮接口。
- 票价、开放时间、地址、图片 URL、经纬度等扩展字段。
- 景点图片本地资源和图片代理，支持 Wikimedia 缩略图及百度图片域名。
- 支持导入合法获取的 Overpass JSON 和 Geofabrik OSM PBF 数据。
- OSM 导入按来源对象编号幂等更新，并保留来源链接、坐标和许可所需信息。
- 核心数据重建、字段补全、图片抓取和演示数据初始化脚本。

## 4. 收藏、行程与推荐

- 收藏景点、查询当前用户收藏、取消收藏后列表即时刷新。
- 创建、查询、编辑和删除个人行程。
- 行程支持起止日期、备注和每日景点安排。
- 行程与景点关联记录使用外键和用户归属校验，用户不能读取其他用户的行程。
- 按用户收藏城市推荐尚未收藏的同城景点。
- 根据行程生成社交分享文案；配置 Ark 模型时使用模型生成，未配置或调用失败时
  使用规则模板降级，保证演示可用。

## 5. AI 助手与服务器连接

- `GET /api/agent/status`：查询 AI 服务是否已配置。
- `POST /api/agent/chat`：旅行问答，支持多轮历史。
- `POST /api/agent/plan`：根据自然语言、城市和天数生成行程，可直接保存。
- 对模型返回的景点 ID 进行服务端二次校验，过滤不存在的景点。
- 通过火山引擎方舟（Ark）的 OpenAI 兼容接口连接模型，支持环境变量或
  `instance/agent.env` 配置 `ARK_API_KEY`、`ARK_MODEL` 和 `ARK_BASE_URL`。
- 未配置密钥时自动使用规则版问答/行程结果，不影响本地页面和测试。
- 密钥文件位于被 Git 忽略的 `instance/` 目录，不进入仓库。

## 6. 旅行足迹与分享

- `GET /api/footprint` 聚合当前用户的收藏和行程城市。
- 输出已访问城市、全部可用城市背景、经纬度、景点数、覆盖率和旅行等级。
- 城市名统一归一化，兼容带“市”后缀的城市数据。
- 足迹地图使用前端 SVG 绘制，支持已访问城市高亮和城市信息卡片。
- 使用 Canvas 生成足迹海报并支持下载/分享。
- 足迹接口要求登录，数据只按当前用户查询，不新增业务表。

## 7. 服务、数据和质量保障

- Flask 应用工厂支持 development、testing、production 三种配置。
- SQLite 数据库连接、事务、外键、WAL 和 UTC ISO 8601 时间统一管理。
- 数据库初始化和各模块迁移可重复执行，不覆盖已有业务数据。
- 统一 JSON 响应结构：`success`、`message`、`data`。
- 健康检查接口：`GET /api/health`。
- 生产环境强制要求 `TRAVELMATE_SECRET_KEY`，并设置安全响应头。
- 当前合并后的测试结果：`54 passed`。
